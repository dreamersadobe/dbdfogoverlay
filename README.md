# 🔥 DBD Fog Overlay

Оверлей для Dead by Daylight, отображающий сайт [dbdfog.ru](https://dbdfog.ru) поверх игры.
Смотри билды, не сворачивая игру!

## 📥 Скачать

Перейди в раздел [**Releases**](../../releases/latest) и скачай последний `.exe` — установка не требуется.

## 📋 Требования

- **Windows 10/11**
- Dead by Daylight в режиме **Borderless Windowed** (Безрамочный оконный)

> Для запуска из исходников дополнительно нужен **Node.js** 18+ ([скачать](https://nodejs.org)).

## 🚀 Быстрый старт (из исходников)

```bash
# Клонируй репозиторий
git clone https://github.com/marginallix/dbdfogoverlay.git
cd dbdfogoverlay

# Установи зависимости
npm install

# Запусти оверлей
npm start
```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Alt+F1` | Показать / Скрыть оверлей |
| `Alt+F2` | Переключить режим мыши (прозрачный ↔ интерактивный) |
| `Alt+F3` | Увеличить непрозрачность |
| `Ctrl+Alt+F4` | Уменьшить непрозрачность |
| `Alt+F5` | Сбросить позицию и размер |

## 🎮 Как пользоваться

1. Запусти оверлей (`.exe` или `npm start`)
2. Запусти Dead by Daylight в режиме **Borderless Windowed**
3. Оверлей появится в правом верхнем углу экрана
4. По умолчанию оверлей в режиме **прозрачности** — клики проходят в игру
5. Нажми `Alt+F2` чтобы переключиться в **интерактивный режим** и взаимодействовать с сайтом
6. Нажми `Alt+F2` ещё раз чтобы вернуться в режим прозрачности

## 🖱️ Режимы мыши

- **🔓 Прозрачный** — все клики проходят в игру, оверлей только для просмотра
- **🖱️ Интерактивный** — можно кликать по сайту, скроллить, переходить по ссылкам

## 🔧 Трей

Оверлей создаёт иконку в системном трее (около часов). Правый клик для дополнительных настроек:
- Показать / скрыть
- Переключить режим мыши
- Изменить прозрачность
- Перезагрузить сайт
- Сбросить позицию
- Выйти

## ⚙️ Настройки

Отредактируй файл `config.json` в папке с программой:

```json
{
  "url": "https://dbdfog.ru",
  "width": 500,
  "height": 700
}
```

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `url` | Адрес сайта | `https://dbdfog.ru` |
| `width` | Ширина оверлея (px) | `500` |
| `height` | Высота оверлея (px) | `700` |

## 📦 Сборка .exe

```bash
# Портативный .exe (без установки)
npm run build

# Установщик .exe
npm run build-installer
```

Готовый файл появится в папке `dist/`.

## ⚠️ Важно

- Игра **ДОЛЖНА** быть в режиме **Borderless Windowed**, иначе оверлей не будет виден
- Оверлей **НЕ** вмешивается в файлы игры и **НЕ** является читом
- Это просто браузерное окно поверх игры
